# Guide graphique

Ce guide sert à créer les images du jeu avec un générateur d'images, comme celui de ChatGPT. Le but : que toutes les images aient l'air de venir du même jeu. Les emojis actuels du jeu sont provisoires, ce sont eux que ces images remplaceront, dans les fiches comme sur les cartes de la cité et des alentours.

## Le style

Colle ce bloc au début de chaque demande, mot pour mot :

> Illustration pour un jeu de stratégie médiéval-fantastique, peinte à la main, style aquarelle et encre, contours sombres et nets, couleurs profondes (bleu nuit, or, pierre grise, vert forêt), lumière douce venant du haut à gauche. Un seul sujet, centré, sur fond transparent. Format carré. Pas de texte, pas de cadre, pas de signature.

Ce style est une proposition : l'aquarelle et l'encre vont bien avec le thème sombre et doré du jeu, et ce style reste cohérent d'une image à l'autre. Si tu préfères autre chose (dessin animé, pixel art, réaliste…), on change ce bloc et toutes les images suivent.

## Les règles

- Toujours le même bloc de style, puis la description de l'image, une image par demande.
- Fond transparent, format PNG. Si l'image arrive avec un fond, redemande-la.
- Ne jamais citer un autre jeu, un studio ou un artiste (« dans le style de… ») : notre style doit rester le nôtre.
- Garde une image seulement si elle va avec les précédentes. Sinon, refais-la.
- Commence par les cinq ressources : ce sont les images les plus visibles du jeu.

## Quand des images sont prêtes

1. Pour avoir un avis avant de faire toute la série, montre-moi une ou deux images ici, dans la conversation.
2. Sur GitHub, ouvre le dépôt et dépose les images dans un dossier `images` (bouton **Add file**, puis **Upload files**), avec exactement les noms de fichiers ci-dessus.
3. Préviens-moi : je les intègre dans le jeu.
